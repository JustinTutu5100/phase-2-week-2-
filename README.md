# Smart Goal Planner

A simple local web app to help you set, track, and manage savings goals.

You can:

- Add new goals (e.g., “New Laptop” or “Travel Fund”)
- Edit a goal’s name, target amount, category, and deadline
- Make deposits and see your progress
- View total goals, total saved money, and number of completed goals
- See goal status like In Progress, Warning, Overdue, or Completed
- View completed goals in a separate list

Made with react.
